# Lernzentrale_Medien_Fahrrad

Medien für das Serious Game „Der Fahrrad-Detektiv“ der Lernzentrale KVF der BbS IV „Friedrich List“ Halle (Saale).
Das Spiel liegt im Repo `Lernzentrale_KVF` (https://friedrichlist.github.io/Lernzentrale_KVF/SG_LF04_Fahrrad_Detektiv.html) und lädt diese Dateien von
https://friedrichlist.github.io/Lernzentrale_Medien_Fahrrad/ – erst dann, wenn sie im Spiel drankommen. Ohne diese Dateien bleibt das Spiel spielbar (Text statt Bild und Film).

Bilder, Videos und Stimmen KI-generiert (Google Gemini, Kling AI). Handlung und Personen sind frei erfunden.
Gebaut im OneDrive unter `KVF/Interaktive Lernzentrale` mit `Werkzeug/sg/medienpaket.py` (verkleinert: Clips etwa 0,5 Mbit/s, Bilder JPEG 80, Ton MP3 mono 64 kbit/s); hier nichts von Hand ändern.

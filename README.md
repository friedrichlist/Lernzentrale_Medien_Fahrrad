# Lernzentrale_Medien_Fahrrad

Medien (Bilder, Filme, Stimmen, Atmo, Geräusche) für das Serious Game „Der Fahrrad-Detektiv“ der Lernzentrale KVF der BbS IV „Friedrich List“ Halle (Saale).
Das Spiel selbst liegt im Repo `Lernzentrale_KVF` (https://friedrichlist.github.io/Lernzentrale_KVF/SG_LF04_Fahrrad_Detektiv.html) und lädt diese Dateien von
https://friedrichlist.github.io/Lernzentrale_Medien_Fahrrad/ – erst dann, wenn sie im Spiel drankommen. Ohne diese Dateien bleibt das Spiel voll spielbar (Text statt Bild und Film).

Bilder, Videos und Stimmen sind KI-generiert (Google Gemini, Kling AI). Handlung und Personen sind frei erfunden.
Geräusche: Pixabay (Content License). Gebaut im OneDrive unter `KVF/Interaktive Lernzentrale` (`Werkzeug/sg/medienpaket.py`); hier nichts von Hand ändern.
